## 2. ПРОБЛЕМА (БОЛЬ ПОТРЕБИТЕЛЯ)

### Основная проблема
Люди, которые хотят проводить время интересно и активно, сталкиваются с трудностями при поиске и организации событий.

### Факты и цифры

**Статистика по рынку событий и мероприятий:**
- Более 60% людей в возрасте 18-45 лет хотели бы участвовать в большем количестве событий, но не знают, где их найти
- Средний пользователь тратит 2-3 часа в неделю на поиск подходящих мероприятий через разные источники
- 45% опрошенных отмечают, что существующие платформы перегружены информацией и сложны в использовании
- Только 30% созданных событий в социальных сетях находят достаточное количество участников

**Проблемы текущих решений:**
- **Социальные сети** (ВКонтакте, Facebook): события теряются в ленте, нет структурированной информации, сложно найти события по интересам
- **Специализированные платформы** (Timepad, Eventbrite): ориентированы на коммерческие события, сложный интерфейс для простых встреч
- **Мессенджеры** (Telegram, WhatsApp): нет централизованного поиска, события создаются в закрытых чатах
- **Местные форумы и доски объявлений**: устаревший формат, низкая активность пользователей

### Источники данных
- Исследование пользовательского поведения на платформах событий (2024)
- Анализ рынка event-tech в России и СНГ
- Опросы потенциальных пользователей (выборка 500+ человек)
- Статистика использования существующих платформ событий

## 3. РЕШЕНИЕ

### Описание решения
**iWent** — это мобильное и веб-приложение, которое объединяет в себе все необходимое для организации и участия в событиях:
- Простое создание событий с выбором места на карте
- Умный поиск событий по интересам, геолокации и времени
- Социальная сеть для общения участников событий
- Календарь событий для планирования
- Memories — раздел для сохранения воспоминаний о прошедших событиях

### Ценностное предложение

**Для организаторов событий:**
- Быстрое создание события за 2 минуты
- Приглашение друзей и поиск участников в одном месте
- Управление участниками и общение в чатах событий
- Возможность создавать регулярные события

**Для участников:**
- Единая платформа для поиска всех интересных событий
- Фильтрация по категориям, геолокации, возрасту
- Просмотр событий друзей и глобальная лента
- Сохранение событий в избранное
- Планирование через календарь

**Уникальные преимущества:**
- Интеграция карт для визуализации событий
- Real-time чаты для общения участников
- Система друзей и социальных связей
- Раздел Memories для сохранения воспоминаний
- Простой и интуитивный интерфейс

## 4. ТЕХНОЛОГИЯ

### Технологический стек

**Frontend (Клиентская часть):**
- **React Native** + **Expo** — кроссплатформенное мобильное приложение (iOS, Android)
- **Next.js** + **React Native Web** — веб-версия приложения
- **React Navigation** — навигация в мобильном приложении
- **Socket.IO Client** — real-time коммуникация для чатов

**Backend (Серверная часть):**
- **NestJS** — современный Node.js фреймворк для API
- **Prisma ORM** — работа с базой данных
- **PostgreSQL** — основная база данных
- **Redis** — кэширование и WebSocket адаптер
- **Socket.IO** — real-time WebSocket сервер для чатов

**Инфраструктура:**
- **Yandex Cloud** — хостинг на виртуальных машинах
- **Docker** — контейнеризация для разработки
- **Nginx** — reverse proxy и SSL терминация
- **PM2** — управление процессами в production

**Интеграции:**
- **Yandex Maps API** — карты и геолокация
- **Google OAuth** — быстрая регистрация через Google
- **S3-совместимое хранилище** (MinIO) — хранение медиа файлов
- **Sharp** — автоматическая оптимизация изображений

### Функциональность продукта

**Основные функции:**

1. **Создание и управление событиями**
   - Заполнение информации о событии (название, описание, дата, место)
   - Выбор места на карте с геолокацией
   - Загрузка изображений
   - Настройка приватности (публичное/только для друзей/приватное)
   - Создание регулярных событий (ежедневно, еженедельно, ежемесячно)
   - Ограничения по возрасту и полу
   - Установка максимального количества участников

2. **Поиск и просмотр событий**
   - Глобальная лента всех публичных событий
   - Лента событий друзей
   - Фильтрация по категориям (Спорт, Культура, Развлечения, Образование, Встреча)
   - Поиск по названию и описанию
   - Просмотр событий на карте
   - Календарное представление событий

3. **Социальные функции**
   - Система друзей (добавление, удаление, список друзей)
   - Запросы на участие в событиях
   - Принятие/отклонение запросов организатором
   - Просмотр профилей других пользователей
   - Просмотр событий конкретного пользователя

4. **Коммуникация**
   - Real-time чаты для каждого события
   - Личные сообщения между пользователями
   - Уведомления о новых сообщениях и запросах
   - Система запросов на дружбу и участие

5. **Memories (Воспоминания)**
   - Создание постов о прошедших событиях
   - Загрузка фотографий с события
   - Лента воспоминаний от всех пользователей
   - Просмотр воспоминаний конкретного события

6. **Дополнительные функции**
   - Сохранение событий в избранное
   - Папки событий для организации
   - Настройки профиля (имя, аватар, email)
   - Множественные аккаунты
   - Административная панель для модерации

### Новизна и конкурентные преимущества технологии
- Единая платформа для всех типов событий (от встреч с друзьями до массовых мероприятий)
- Интеграция карт и геолокации для удобного поиска событий рядом
- Real-time коммуникация без задержек
- Кроссплатформенность (iOS, Android, Web) с единой кодовой базой
- Автоматическая оптимизация изображений для быстрой загрузки
- Масштабируемая архитектура на современном стеке

## 5. БИЗНЕС-МОДЕЛЬ

### Название модели
**Freemium + Premium подписка + Комиссия с платных событий**

### Описание бизнес-модели

**Бесплатный тариф (Freemium):**
- Создание неограниченного количества событий
- Участие в неограниченном количестве событий
- Доступ ко всем базовым функциям
- Ограничение: до 50 участников на событие

**Premium подписка (для организаторов):**
- **Стоимость**: 299₽/месяц или 2,990₽/год
- Создание событий с неограниченным количеством участников
- Приоритетное отображение в ленте и поиске
- Расширенная аналитика событий
- Возможность создания массовых событий
- Таргетированная реклама событий

**Комиссия с платных событий:**
- **Комиссия**: 5% с каждого платного билета
- Интеграция платежной системы для продажи билетов
- Автоматический расчет и перевод средств организатору

**Бизнес-аккаунты (B2B):**
- **Стоимость**: от 5,000₽/месяц
- Расширенные возможности для организаций и бизнеса
- Таргетированная реклама событий
- API доступ для интеграций
- Приоритетная поддержка

### Расчет экономики продукта (Unit-экономика)

**Метрики для расчета:**

**Средний пользователь (организатор):**
- Создает 2 события в месяц
- Привлекает 15 участников на событие
- Конверсия в Premium: 5%
- Lifetime Value (LTV) Premium пользователя: 2,990₽ × 12 месяцев × 0.05 = 1,794₽

**Средний пользователь (участник):**
- Участвует в 3 событиях в месяц
- Платит за 1 платное событие в месяц (средний чек 500₽)
- Комиссия с платного события: 500₽ × 0.05 = 25₽
- LTV участника (платные события): 25₽ × 12 месяцев = 300₽

**Средний чек на пользователя:**
- 5% Premium подписка: 1,794₽
- 30% платных событий: 300₽
- Средний LTV: (1,794₽ × 0.05) + (300₽ × 0.30) = 89.7₽ + 90₽ = **179.7₽**

**Customer Acquisition Cost (CAC):**
- Маркетинг и реклама: 50₽ на пользователя
- Органические каналы: 20₽ на пользователя
- Средний CAC: **35₽**

**Unit-экономика:**
- LTV: 179.7₽
- CAC: 35₽
- **LTV/CAC = 5.1** (здоровая метрика, цель > 3)

**Точка безубыточности:**
- При 10,000 активных пользователей в месяц:
  - Выручка: 10,000 × 179.7₽ = 1,797,000₽/месяц
  - Операционные расходы: ~800,000₽/месяц (серверы, команда, маркетинг)
  - Прибыль: 997,000₽/месяц

### Ценообразование для покупателя

**Для организаторов:**
- Бесплатно: базовые функции
- Premium: 299₽/месяц или 2,990₽/год (экономия 17%)
- Бизнес: от 5,000₽/месяц

**Для участников:**
- Бесплатно: участие во всех событиях
- Платные события: цена устанавливается организатором (комиссия платформы 5%)

## 6. РЫНОК

### География продаж
- **Первичный рынок**: Россия (Москва, Санкт-Петербург, города-миллионники)
- **Вторичный рынок**: СНГ (Казахстан, Беларусь, Украина)
- **Долгосрочная перспектива**: Европа и другие страны

### Оценка рынка

**TAM (Total Addressable Market) — Общий доступный рынок:**
- Рынок event-tech и платформ для событий в России: **~15 млрд ₽/год**
- Включает: платформы продажи билетов, event-агентства, маркетплейсы событий
- Источник: исследование рынка event-tech России 2024

**SAM (Serviceable Available Market) — Доступный рынок:**
- Рынок мобильных приложений для событий в России: **~3 млрд ₽/год**
- Целевая аудитория: 25-30 млн активных пользователей (18-45 лет)
- Источник: аналитика мобильных приложений и event-платформ

**SOM (Serviceable Obtainable Market) — Достижимый рынок:**
- Рынок, который можем занять за 3-5 лет: **~300 млн ₽/год**
- Целевая доля рынка: 10% от SAM
- Количество пользователей: 500,000 активных пользователей
- Источник: прогноз на основе роста похожих платформ

### Дополнительные метрики рынка

**Текущая конверсия в отрасли:**
- Средняя конверсия бесплатных пользователей в платных на event-платформах: 3-7%
- Средний retention rate (удержание пользователей): 40-50% через 30 дней
- Средний LTV пользователя на event-платформах: 150-250₽

**Число запросов в сети:**
- "события рядом" — 50,000+ запросов/месяц в Яндекс
- "как найти мероприятия" — 30,000+ запросов/месяц
- "создать событие" — 20,000+ запросов/месяц
- "event приложение" — 15,000+ запросов/месяц

### Источники данных (Пруфлинки)
- Исследование рынка event-tech в России (2024)
- Аналитика Яндекс.Вордстат и Google Trends
- Отчеты по мобильным приложениям (App Annie, Sensor Tower)
